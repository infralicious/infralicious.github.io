# Security Policy

## Report a vulnerability

Use the [contact form](https://infralicious.com/contact.html).
Describe the issue, the page or feature, and steps to reproduce it.
Do not publish the issue before we fix it.

## Scope

This policy covers the Infralicious website and docs in this repo.
For TrueTime for Jira, use the same contact form.

## Response

We reply within 1 business day, per our [support SLA](https://infralicious.com/sla.html).
